What it is

A feature-rich recompilation launcher for Fire Emblem: Fortune's Weave, with integrated mod management and in-game enhancements. It builds the game from your own dump and plays it natively on Windows. fefw-recomp is its integrated engine. No game code, assets, firmware or keys are included or downloaded.

Current graphics

  • FSR 4.1.2 / 3.1 upscaling, plus FSR 3 frame generation validated at 60 rendered → 120 presented fps on an RX 7900 XT.
  • Built-in TAAU, FSR 1, NVIDIA Image Scaling, DLSS / DLAA and XeSS, each with an availability check.
  • Optional ReShade: the launcher detects the Vulkan layer, opens the official setup for fefw.exe, and can switch it off for this game only. ReShade is never bundled.
