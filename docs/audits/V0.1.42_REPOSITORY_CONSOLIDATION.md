**Overlap check.** The four Freebuff commits touch only `apps/emblemweave/src/pages/saves.rs`,
`apps/emblemweave/src/savefile.rs`, `apps/emblemweave/src/savefile/gamedata.rs` and

work. FCC does modify `apps/emblemweave/src/engine.rs` and `main.rs`, which are **not** touched by Freebuff
commits.

**Decisions taken because of FCC**

- No FCC file was edited, reverted, staged or committed.
- The canonical launcher build was produced from `git archive HEAD` in
  `target/canonical-v0142/src`, so FCC's uncommitted Rust changes could not leak into the release binary.
- A clean production C++ engine build was **not** attempted. It would compile FCC's uncommitted engine files
  and would contend for the same build tree. This is recorded as a release blocker, not as a passing build.
- FCC's report files were left untracked and unmodified. Their claims are treated as FCC evidence, not as
  independently verified release evidence.

FCC's `FCC_FINAL_REPORT.md` describes the repository as clean and all work consolidated. That is not the state
observed here: 24 tracked files remain modified and 9 paths remain untracked. The report therefore cannot be
used as proof of a clean release tree.
