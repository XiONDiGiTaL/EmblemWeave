# EmblemWeave 0.1.29

> Three installs left the requirements: Git, PowerShell 7 and uv

The build needed ten things installed. It needs seven now, and the three that went were only ever there for one job each.

## Git: the build downloads its sources instead

`tools\textures\scripts\fetch_third_party.ps1` cloned astc-encoder and bc7enc_rdo. It now downloads the same two revisions as
release archives with `curl.exe` and unpacks them with `tar.exe`, both of which Windows has had since 10, checks each against a
pinned SHA-256 before unpacking, and leaves the folders where the build expects them. ispc was already fetched as a zip this way.

## PowerShell 7: Windows PowerShell runs the scripts

The engine's scripts use nothing that only PowerShell 7 understands, so the launcher runs `pwsh` when it is installed and
`powershell.exe` otherwise. PowerShell 7 stays a faster option, not a requirement.

## uv: Python and pip make the environment

`uv` made `tools\.venv` and installed `recomp\requirements.txt`. Without it the launcher runs `py -3 -m venv` (then `python -m venv`
when the py launcher is absent) and installs the same pinned list with that environment's own pip. uv is still used when present,
because it pins 3.13 and is quicker.

## What is still required

Visual Studio C++ tools with the Windows SDK, LLVM, CMake, Ninja, NASM (dav1d's AVX assembly for AV1 movies) and Python 3.9 or
newer. The Requirements page lists Git, PowerShell 7 and uv as optional, and the README table is regenerated from the same registry.

## Verified

- A full engine build under **Windows PowerShell 5.1** (`powershell.exe -File game-build/scripts/build_fefw.ps1`): reached
  `[6/7] Linking CXX executable fefw.exe` and exited 0, so nothing in the build needs PowerShell 7.
- `fetch_third_party.ps1` run under Windows PowerShell 5.1 with a PATH holding only `C:\Windows\System32` (no Git, no uv):
  downloaded both archives, matched both SHA-256 hashes, and left `third_party\astc-encoder` and `third_party\bc7enc_rdo` in place.
- `py -3.14 -m venv` plus `pip install -r recomp\requirements.txt`: exit 0, the same packages the uv path installs.
- `cargo build --release` and `cargo test -p emblemweave`: 119 passed, 0 failed.
- Not checked: the uv-absent branch inside the launcher itself (uv is installed on this PC, so the build takes the uv path); the
  commands it runs were the ones run by hand above.
