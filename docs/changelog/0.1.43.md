# EmblemWeave 0.1.43

> Fixes the runtime build failing with "The input line is too long" in a launcher-started build on a long Windows environment.

**Status: official release, 2026-11-25.** 0.1.43 is the current public release and 0.1.42 is the previous one. This is a focused build-reliability release; the field limitations recorded in the 0.1.42 changelog are unchanged.

## Build reliability

- **The final `fefw.exe` step reuses the launcher's toolchain environment.** The launcher runs `vcvars64.bat` once, then exports `INCLUDE`, `LIB` and `PATH` with `NX_ENV_READY`. The recompilation step passed that handshake, but the separate `build_fefw.ps1` step did not. Its `env.cmd` therefore ran `vcvars64.bat` a second time, appending another toolchain to an already long environment. The child `cmd.exe` refused the line with `The input line is too long` and the runtime configure never started. The final step now receives `NX_ENV_READY`, and `runtime/scripts/env.cmd` returns immediately when that handshake and the launcher's `INCLUDE` and `LIB` are present.
- **Regression coverage.** `engine/fefw-recomp/recomp/scripts/check_cmd_scripts.ps1` now checks `runtime/scripts/env.cmd` with `NX_ENV_READY`, `INCLUDE`, `LIB` and a 7,906-character PATH. The packaging script runs this check before it packs anything.

The patched launcher built the runtime from the official engine sources: `fefw.exe` is 170,068,992 bytes. The built runtime opened the game window with the title `Fire Emblem: Fortune's Weave | FPS: 46`, reached `startup ready` at 16.86 seconds, and was stopped cleanly after 25 seconds.
- This is a Windows x64 release. Linux and Steam Deck still have no downloadable 0.1.43 artifact; the native engine build remains incomplete and the Proton route is compatibility, not native Linux support. See `docs/STEAMDECK.md`.
- The local E: installation is updated from the official 0.1.43 package after publication. Its `data` folder, saves, settings and built game are preserved.
