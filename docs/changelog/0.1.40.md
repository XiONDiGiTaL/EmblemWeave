# EmblemWeave 0.1.40

> Update and Play without a rebuild, cleaner add-on failures, and a bounded packed-audio cache.

## Launcher

- **Updating no longer asks for a rebuild.** The updater records the existing build as carried forward in `fefw.ini`.
  Overview opens ready to play after the restart: the **This game folder came from another release** card, and its
  Repair/Rebuild action, are not shown for a build the updater deliberately kept. `built_by` remains the release that
  compiled the build, so diagnostics still name it, and a launcher copied in by hand still gets the mixed-folder warning.
  The first start after an update installed by 0.1.39 also records the carry from the matching release left in the update
  cache.
- The update still replaces the launcher, docs and engine sources in place, restarts once, and keeps `data\`,
  `engine\fefw-recomp\game-build`, the fetched build tools and third-party sources, and the portable/profile choice.
  The previous build is kept in `backups\EmblemWeave.exe.old` instead of beside the launcher, and a file an older
  version left at the install root is moved there on the first start; `logs\update.log` is unchanged.

## Game data

- `.nsp` and `.xci` add-on scanning now clears the managed DLC folder when the add-on scan fails, so an encrypted or
  malformed add-on NCA cannot leave an old pack for detection to find. The base game and its RomFS remain detectable while
  the add-on itself is refused.
- `.xci` secure-partition add-on extraction and the managed marker are covered through the same `detect_with` path as
  `.nsp`; a real encrypted retail XCI is still refused with the no-keys message.
- `.nsp`/`.xci` program and control lookup skips unreadable optional NCAs instead of parsing every NCA, so one bad add-on
  cannot hide the base game.

## Engine

- The packed `.nup` RomFS cache is now a bounded LRU: 1.5 GiB total, 256 MiB per file, evicting least-recently-used
  entries and not retaining oversized files. A packed `.elf.zst` audio file can no longer fill the budget or clear every
  cached file at once. New stats report retained bytes, peak, files, evictions and skipped entries, and the peak-memory
  test covers a synthetic packed audio file.
