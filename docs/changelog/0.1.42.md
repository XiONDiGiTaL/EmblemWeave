# EmblemWeave 0.1.42

> Cinematic playback infrastructure complete, Find Units cheat optimized, title return crash fixed, HDR state restored, save directory reconciliation implemented.

## Critical Fixes

- **Issue #77: Crash returning to title (FIXED).** The game now runs 120+ seconds (4000+ frames) stably without the write fault crash at ~4s, read fault crash at ~6.3s, or "second exception inside crash handler" at ~8s. Root cause was ImportFreeze making pages read-only before installing the page fault handler, and the handler lacking broad fallback for PAGE_NOACCESS pages left by the Vulkan driver.

## Infrastructure Complete (Field Testing Pending)

- **Issue #75: Cinematic playback (AV1 + Opus).** dav1d AV1 decoder with x86-64 assembly, WebM AV1CodecConfigurationRecord parsing with variable-length OBU extraction, MP4 av1C fallback, hwopus Opus decoder via FFmpeg (dynamic DLL loading), D3D11VA hardware acceleration configured (8 threads, 30 frames ahead).

- **Issue #76: Find Units cheat stuttering.** Parallel memory scanning with worker threads, cancellation tokens, progress reporting, thread priority BELOW_NORMAL, 30s timeout, 2GB memory limit, 8 thread cap.

- **Issue #78: HDR remains enabled after exit.** `play.cpp` stop() restores windowed mode before marking play stopped; HDR tied to fullscreen/borderless mode on Windows.

## Issue #79: Save Files Not Being Read (IMPLEMENTED)

- **R1: INI reconciliation.** `sync_save_dir()` in `engine.rs` reconciles `[fs] save_dir` in fefw.ini with `Config::save_dir()` before every Play, fixing the root mismatch that survives rebuilds.

- **R2: UI path display.** Game Setup and Saves pages now show the effective save folder from fefw.ini alongside the configured folder, with a mismatch warning when they differ.

- **R3: Orphan save adoption.** New `find_orphan_saves()` and `adopt_orphan_save()` in `saves.rs` discover saves in profiles/ or non-DEFAULT_USER account folders and adopt them into the game's account save with consent and automatic backup.

- **R4: Runtime loud auto-create.** `save_dir()` in `common.cpp` now logs when it creates the save directory (configured or fallback), making silent auto-creation visible in logs.

- **R5: Diagnostic bundle evidence.** Report bundle includes save directory reconciliation status (configured vs effective, match/mismatch).

- **R7: Safe reconciliation.** `sync_save_dir()` now copies the save out of the INI's folder into the launcher's folder before rewriting the INI. It never repoints the game at an empty folder, and a failed copy leaves the INI pointing at the save the game already reads.

- **R8: The other launcher data root is offered.** `survey_here()` lists `%APPDATA%\EmblemWeave\save` and `<install>\data\save` when they are not the root in use, so a playthrough stranded by switching between portable and AppData storage can be imported as a new profile (or into the current save) with the usual backup.

- **Verified with a real emulator save.** Eden is configured with `nand_directory=C:/Users/xiond/AppData/Roaming/yuzu/nand`, so Eden and Lichii read the same FEFW save under yuzu's NAND. `--import-save` on that folder copied 10 files into the engine's `account/<uid>/000`, wrote the `.meta`, moved the previous save to `backups/`, and left an existing profile byte-identical. Profile import was verified by test: a yuzu title folder becomes a new profile and never replaces a profile or the current save. The issue stays open until the reporter confirms on their own install.

## Engine Stability

- **write_watch null g_transitions crash (FIXED).** ImportFreeze constructor now lazily initializes `g_transitions` RWLock under mutex and installs fault handler before making pages read-only.
- **Broad read fault fallback.** Handles committed PAGE_NOACCESS pages not tracked by any region.
- **Write fault fallback hardening.** Fallback 1 & 2 check `protect()` return value and balance `g_busy` on failure; Fallback 4 handles write faults on decommitted (PAGE_NOACCESS) pages still in a region.
- **ImportFreeze for all pools.** NVN pool import creates ImportFreeze for all pool types, not just viewed pools.
- **heap_decommit clears retired bit.** Prevents retired page race on scene teardown (commit 406e46f).
