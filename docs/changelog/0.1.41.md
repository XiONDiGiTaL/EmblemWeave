# EmblemWeave 0.1.41

> A measured performance controller, a Performance page, a themed nine-tab F1 menu, 200% master volume, real Vulkan GPU selection, save portraits and party cheats, and no drag glide.

## Performance

- **Adaptive Performance Controller.** A 300-frame window classifies CPU, GPU, VRAM, streaming, shader-compilation,
  scheduling and synchronization pressure. It reports average FPS, 1 % and 0.1 % lows, P50/P95/P99, CPU/GPU/upload/replay
  time and shader backlog, and writes `play/perf_status.json` once a second for the launcher.
- **Frame-Time Stability.** Recurring spikes are counted, and a detail increase is held back while a spike settles. The
  controller adds no synchronization to the frame loop.
- **Scene-aware profiles.** Exploration, crowded, combat, cinematic, menu and loading are recognised from workload shape,
  not location names. Combat and cinematics resist detail changes; an override is available for A/B runs.
- **Operating modes.** Automatic, Conservative, Balanced, Aggressive and Manual. Every action appears in the F1 status
  and event list; Manual never actuates. Disabling the controller releases its only live visual change.
- **Adaptive texture detail (experimental).** Under sustained GPU or VRAM pressure, a sampler LOD offset moves toward
  cheaper mips and is released when pressure ends. The user's `[nvn] lod_bias` is never rewritten, and the native UI
  uses a separate path and stays sharp.
- **Existing systems are exposed, not duplicated.** Background texture preparation, upload staging and budgets, VRAM
  residency, lean draw replay, pipeline prewarm and the pipeline library are controllable from the launcher and F1 with
  their real keys. The shared shader-worker cap stays on Graphics so it has one owner.

## Interface

- The F1 menu is now nine XiØN tabs: Overview, Graphics, Performance, Upscaling, Pacing, Audio, Advanced (Controls /
  Game / Mods), Diagnostics and System. Controls, Game and Mods keep their functionality.
- `nxrt/ui_theme.h` is the single token source for backgrounds, surfaces, text, borders, accent, success/warning/error
  and geometry. The F1 menu, FPS counter, compile/mods notes, pointer, on-screen keyboard, diagnostics, audio panel and
  legacy settings rows use it.
- Sora (SIL Open Font License) ships as the Latin UI face, with DejaVu and Segoe UI fallbacks. Chinese, Japanese and
  Korean UI packs keep their CJK-capable faces.
- The ReShade overlay can be given the XiØN palette through ReShade's documented `[STYLE]` custom-style keys
  (`StyleIndex=4`). No binary is patched; a one-time `ReShade.ini.xion-backup` keeps the previous style. The native
  overlays do not depend on this setting, and the ReShade result was not visually verified in this release.

## Audio (#60)

- **Master volume up to 200%.** The Audio page's Master slider now runs from 0 to 200%. Moving it above 100% for the
  first time asks **I know the risks** or **Cancel**; a confirmed boost is written as `[audio] volume` in
  `controls.ini` (up to `2.00`) with two decimals. The engine mixes at that gain and its peak limiter prevents digital
  clipping.
- The F1 menu's Audio tab uses the same range and reads back the value the launcher wrote, so a change made in either
  place appears in the other. A regression test covers a 185% write and a 200% value adopted from the engine.

## GPU choice (#66)

- **The GPU dropdown lists the actual adapters.** Advanced Graphics now enumerates the machine's Vulkan 1.3 physical
  devices at start and shows each one by name, adapter type and video memory, alongside **Automatic**, **Discrete** and
  **Integrated**. On the test PC it reports `AMD Radeon RX 7900 XT (Discrete, 20464 MiB)`.
- Choosing an adapter writes its full Vulkan name to `[gfx] gpu`. The engine already accepts a case-insensitive part of
  a device name, so the selection reaches the exact adapter without depending on the loader's enumeration order; a
  category still selects by type, and a name that no longer matches falls back to the engine's default with a log line.
- The device scan is dynamic: the launcher does not link Vulkan. A machine without the loader keeps the three category
  choices and the page says why no device names are shown.

## Save profiles and cheats

- A save profile's automatic portrait follows the route lord recorded in its newest readable save (Cai, Dietrich,
  Theodora, Leda or Eshmel). The small pencil at the top-right of a profile card opens the portrait picker directly;
  the Manage Saves dialog edits the same choice.
- **Party & free time** cheats: an item pickup multiplier for existing convoy stacks of 2 or more (new rows and
  one-slot gear such as weapons, tomes, staves and shields are left alone) and **Max action points**, which holds the
  current free-time clock so its six-hour turn boundaries do not pass.

## Launcher

- A dedicated **Performance** page groups automatic optimization, rendering, CPU/scheduling, memory/streaming and live
  diagnostics. Unsupported renderer features are stated as limits rather than shown as dead switches.
- The launcher adopts `[perf]`/`[nvn]`/`[gfx]` values changed in the F1 menu back into its pages instead of overwriting
  them on the next Play.
- **Drag glide fixed.** Windhawk's Slick Window Arrangement subclass is removed for the launcher's native move on
  `WM_ENTERSIZEMOVE`, and DWM transitions are disabled for the window. A scripted Win32 probe measured 0 px drift after
  release over 800 ms; Snap state could not be produced on the test host and remains unverified.

## Limits and evidence

- Geometry LOD, GPU occlusion culling, live shadow/effect resizing, dynamic resolution, GPU-driven indirect draws and
  persistent object batching are not exposed: the NVN replay renderer fixes those at startup or has no compatible path.
- No gameplay FPS improvement is claimed for 0.1.41. Representative scene A/B captures were not run here; the
  controller and its percentile report are the infrastructure for those measurements, not a promised speedup.
- The GPU picker's enumeration was checked on the single RX 7900 XT in the test PC. A hybrid laptop with both an
  integrated and a discrete adapter was not available, so switching between two physical adapters in one machine is
  not physically verified; the engine's name-match rule and the launcher's write/adopt path are unit tested.
- `gfx_perf` covers measurement, classification, profiles, the mip action, Manual mode and the menu hold. The full
  launcher suite and both runtime targets build; the modified game executable links.

## Configuration

New keys are documented in `engine/fefw-recomp/runtime/docs/CONFIG.md`: `[perf] enabled`, `mode`, `target_fps`,
`stability`, `scene_profiles`, `scene_override`, `adaptive_mip` and `max_mip_bias`. The existing `[gfx] gpu` key now
also receives a full adapter name from the launcher, and `[audio] volume` accepts the confirmed 0–200% range.
