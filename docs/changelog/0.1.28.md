# EmblemWeave 0.1.28

> Portable mode takes the settings and installed mods with it, and can be switched from the command line

## Portable mode (#29, #21)

A copy of EmblemWeave is portable when `portable.txt` sits beside `EmblemWeave.exe`: everything then lives in `data` next to the
program (game ini and RomFS overlay, shader cache, saves, logs, mods), and the whole folder can be moved, copied or carried on a stick.
A release zip unpacked where no profile exists already becomes portable on its first run, so the button is only for a copy that was
started next to an existing profile.

What was missing was the rest of a profile. Pressing **Keep everything in this folder** copied the saves, and left the theme and display
settings, the save profiles and the installed mods behind, which is not "everything in this folder". It now copies `config.json` and
`play/mods` as well, each only when the portable folder does not already have them, and nothing in the old profile is deleted.

`EmblemWeave.exe --portable on` and `--portable off` do the same as the About button without opening the window, so a support reply can
be one line, and `--portable on` prints where the data folder is.

The About page's note now says what the switch moves, that the built game is rebuilt inside the new folder on the next build, that the
old profile stays as it was, and that an unpacked release zip is already portable.

## Verified

- `cargo build --release` and `cargo test -p emblemweave`: 119 passed, 0 failed.
- In an empty folder holding only the launcher, `--portable on` wrote `portable.txt` and `data\`, copied `config.json`, the save folder
  (with its account subfolder) and `play\mods`, and printed the data folder; `--portable off` removed the marker and left `data\` in
  place.
- The About page was seen on a copy started with `portable.txt` present: `Portable: yes, everything is in this folder`, with the
  folder shown as `…\portable-check\data`.
- Not checked: moving a portable folder to another drive or PC (nothing in it refers to the old path except the built game, which is
  rebuilt), and the button itself was not clicked (the command line calls the same function).
