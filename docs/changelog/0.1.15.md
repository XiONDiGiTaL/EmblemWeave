# EmblemWeave 0.1.15

> Releases are published from the changelog, and this one was published that way

## What's new

- **One source per release.** `pwsh tools/release.ps1 -Version <version>` reads `docs/changelog/<version>.md`, packages the
  build, writes the release notes from that file plus the install steps and the hashes it measured, updates the index
  table, and creates the GitHub release with both assets. The notes and the uploads cannot disagree, because the hashes
  come from the same run.
- **The packager writes a manifest.** `target\pkg\manifest.json` records the version and the name, size and `sha256` of
  each asset; the release notes are built from it.
- **The changelog files carry a summary.** A `> one line` under the title is what the index table shows, so the table is
  generated rather than hand-kept.

## Verification

This release was cut with the new command, which is the test: the notes you are reading were generated from
`docs/changelog/0.1.15.md`, the index gained its row automatically, and the assets were uploaded and quoted by the same
run. `-Local` writes the notes and the index without touching GitHub, which is how the command was checked before it was
used here.

## Still required

Visual Studio 2022 Build Tools with "Desktop development with C++". The .NET 10 SDK is not needed. Steam Deck: the game
runs under Proton, the build does not; `docs/STEAMDECK.md`.
