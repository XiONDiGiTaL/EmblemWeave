# EmblemWeave 0.1.24

> A failed build now says so with the button that runs it again

## Build again

A build that failed used to leave a message that faded after five seconds and nothing to press. The next step was always the same: press
Build the game again, which the build script now does safely on a folder a previous release left in the wrong state (0.1.23).

The failure message now carries **Build again** under it, and stays for a minute instead of five seconds. Pressing it drops the message
and starts the build, with the same progress in the status bar and Diagnostics. Every other message is unchanged: only a failed build
has an action attached.

## Verified

- `cargo build --release` and `cargo test -p emblemweave`: 119 passed, 0 failed.
- Not checked: the message and its button seen on screen. A screenshot of the running launcher was taken while the build was still in
  progress, and the window could not be brought in front of the other windows on this machine to catch the failure state. The button is
  the same widget as the rest of the launcher's buttons, drawn inside the same message box.

## Next

The build folder reset from 0.1.23 runs on its own, so **Build again** is a retry on a clean folder rather than a second attempt with the
same stale cache.
