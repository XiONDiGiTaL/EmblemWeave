# EmblemWeave 0.1.26

> The upscaler hints and the README now name the folder the launcher and the engine actually read

## What changed

0.1.25 added the **Upscaler files** section to Graphics, but the hint under the Upscaling dropdown still sent players to
`upscalers\fsr3 next to the game`, and the README did the same. Neither is wrong (both folders are read), but it is not the
folder the new section names or the one the engine tries first.

- Every upscaler hint now says `upscalers\fsr`, `upscalers\streamline` or `upscalers\xess` in the play folder.
- XeSS joined the Upscaling list and the DLSS replacement list in 0.1.25; the README now documents it, together with the extra
  files DLSS Frame Generation and FSR 3 frame generation need.
- The README describes **Open the upscalers folder** and **Look for the files**, and the F1 menu's `Files found` line they
  answer.

## Verified

- `cargo build --release` and `cargo test -p emblemweave`: 119 passed, 0 failed.
- A full engine build with the 0.1.23 compiler-flag change and the 0.1.24 build-folder reset: `build_fefw.ps1` reached
  `[6/7] Linking CXX executable fefw.exe` and exited 0.
- Not checked: the hint text on screen (it is a string in the same row that was seen in 0.1.25), and a start with real AMD,
  NVIDIA or Intel DLLs, which are not installed here.
